## 2. 포팅 순서 (권장)

1. **공통 CSS 넣기** — 아임웹 관리자 → 디자인 모드 → 설정(톱니) → **코드 삽입** → `<head>` 영역에
   ```html
   <style>
   /* global/site.css 전체 */
   /* global/header-footer.css 전체 */
   /* 05-247/board.css 전체 */
   /* 06-contact/02-form.css 전체 */
   </style>
   ```
   `</body>` 영역에
   ```html
   <script>/* global/reveal.js 전체 */</script>
   ```
2. **헤더 설정** — 아임웹 헤더 설정에서 로고(가로 화이트 또는 컬러, 높이 22~26px), 메뉴는 원스크롤이면 앵커 5개(§2-1), 우측 버튼 「상담 문의」 1개(`#eg-contact`), 스크롤 고정 켜기.
3. **페이지별 섹션 교체** — 각 페이지에서 기존 섹션을 지우고, 섹션 파일 순서대로 **「코드」 위젯**을 하나씩 추가해 파일 내용을 통째로 붙여넣기.
   - 코드 위젯은 아임웹 유료 플랜(일부 플랜)에서만 제공됩니다. 메뉴에 「코드」 위젯이 없으면 「HTML」 또는 「임베드」로 표시됩니다.
   - 코드 위젯의 **좌우 여백 옵션은 0**, 섹션 배경은 「없음」으로 두세요. 섹션 코드가 자체 패딩과 배경을 갖습니다.
4. **푸터** — 아임웹 기본 푸터 내용을 비우고 `06-contact/03-footer.html`을 모든 페이지 맨 아래 코드 위젯으로 넣거나, 「푸터 영역 HTML」이 있으면 거기에 넣습니다.
5. **플레이스홀더 교체** — 코드 안의 `[대괄호]` 텍스트는 전부 바꿔야 할 자리입니다. 검색(Ctrl+F)으로 `[` 를 찾으면 빠짐없이 찾을 수 있습니다.
   - 이미지는 아임웹 「파일 관리」에 올린 뒤 URL 복사 → `src="…"`에 붙여넣기
   - 수치(`[00]%`)는 확인된 값만. 확인 안 되면 해당 블록 삭제

## 2-1. 원스크롤(단일 페이지) 유지 시

현재 사이트는 원스크롤 단일 페이지입니다. 페이지를 나누지 않고 그대로 가려면 홈 한 페이지에 아래 순서로 코드 위젯을 쌓으면 됩니다. 자세한 대응표는 `00-문제점분석.md` §3 에 있습니다.

`01-home/01-hero` → `02-stats` → `03-services` → `05-cases` → `09-cta` → `06-portfolio` → `04-difference` → `07-process` → (현재 「여섯 가지 약속」 섹션 유지) → `08-insights` → `06-contact/01-page-hero` + 아임웹 폼 → `06-contact/03-footer`

헤더 메뉴는 앵커로 연결합니다: 하는 일 `#eg-services` · 성과 `#eg-cases` · 진행 과정 `#eg-process` · 247 `#eg-insights` · 문의 `#eg-contact`.
`02-marketing/`, `03-design/` 는 검색 노출용 서브페이지를 만들 때 씁니다 (§2-2).

## 2-2. 원스크롤과 검색 노출(SEO) — 어떻게 할 것인가

원스크롤 자체가 검색엔진에서 감점되지는 않습니다. 문제는 **URL이 하나뿐**이라는 데서 생깁니다.

- 페이지가 하나면 title·description·h1도 하나라서 노릴 수 있는 검색어 묶음이 하나입니다. 「병원 마케팅」을 노리면 「병원 홈페이지 제작」, 「개원 마케팅」, 「인천 병원 마케팅」 같은 검색어는 각각 자기 페이지가 있는 경쟁사에 밀립니다.
- 앵커(#eg-cases)는 별도 페이지로 색인되지 않습니다. 네이버는 특히 페이지 수와 새 글 빈도를 봅니다.
- 반대로 원스크롤의 장점(한 번에 설득, 이탈 적음)은 랜딩 페이지로서 그대로 유효합니다.

그래서 **홈은 원스크롤 랜딩으로 유지하고, 색인용 페이지를 몇 개 더 두는 하이브리드**를 권합니다.

| 페이지 | 노리는 검색어 | 코드 |
|---|---|---|
| `/` (원스크롤) | 이스터에그, 병원 마케팅 에이전시, 인천 송도 병원 마케팅 | `01-home/` |
| `/MARKETING` | 병원 마케팅, 네이버 플레이스 병원, 개원 마케팅 | `02-marketing/` |
| `/DESIGN` | 병원 홈페이지 제작, 병원 브랜딩, 병원 로고 | `03-design/` |
| `/247` 게시판 | 롱테일 (「개원 체크리스트」, 「병원 블로그 운영」 등 글마다 하나씩) | `05-247/` |
| `/CONTACT` | 상담 문의 (전환용, 검색어 없음) | `06-contact/` |

가장 효과가 큰 건 **247 게시판에 꾸준히 글을 올리는 것**입니다. 서브페이지 2개는 한 번 만들면 끝이지만, 게시판은 글마다 새 URL이 생겨 검색 유입이 쌓입니다. 홈의 `08-insights.html`이 최근 글을 끌어와 홈과 게시판을 연결합니다.

검색엔진에 이미 남아 있는 `/MEDIA` 주소는 미디어 서비스를 접었으므로 아임웹 「리다이렉트」 설정에서 `/`로 301 보내 주세요.

## 7. 자주 생기는 문제

- **폰트가 안 바뀜** → 코드 삽입이 `<head>`에 들어갔는지, `<style>` 태그로 감쌌는지 확인
- **섹션 좌우에 흰 여백** → 코드 위젯/섹션의 패딩을 0으로, "컨테이너 폭" 옵션을 풀폭으로
- **헤더·게시판·폼 스타일이 일부만 적용** → 아임웹 테마마다 클래스명이 달라서입니다. F12 → 요소 선택 → 클래스명을 해당 CSS 셀렉터에 추가
- **스크롤 모션이 안 나옴** → `reveal.js`가 `</body>` 앞에 들어갔는지 확인. 없어도 섹션은 정상 표시됩니다
- **협업 병원 로고 월을 나중에 쓰려면** → git 이력에서 `01-home/06-clients.html`을 복구. 같은 묶음을 두 번 반복해야 끊김 없이 흐릅니다
