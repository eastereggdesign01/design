# 문의 폼 설정 가이드 (아임웹 폼 위젯)

현재 폼: 7항목(성함/직책, 전화번호 3칸, 진료과목, 개원여부, E-mail, 문의내용, 개인정보 동의 + 스크롤 박스) + 영문 「Submit」.
목표: **5항목 + 동의 1줄**, 모바일에서 1분 안에 보내지는 폼.

## 1. 항목 구성

| 순서 | 라벨 | 아임웹 항목 유형 | 필수 | placeholder / 옵션 | 비고 |
|---|---|---|---|---|---|
| 1 | 병원명 · 직책 | 한 줄 텍스트 | 필수 | 예: OO외과 · 원장 | 현재 「성함/직책」을 병원명 중심으로. 이름은 통화 때 확인 |
| 2 | 연락처 | 한 줄 텍스트 (전화번호 유형이 3칸 분리라면 텍스트로) | 필수 | 010-0000-0000 | 3칸 분리 입력 금지. 모바일 키패드가 숫자로 뜨도록 「전화번호」 유형이 한 칸이면 그걸 사용 |
| 3 | 진료과 | 드롭다운 또는 텍스트 | 선택 | 외과 / 정형외과 / 가정의학과 / 치과 / 기타 | 드롭다운이면 분석이 쉬움 |
| 4 | 개원 여부 | 라디오 | 필수 | 운영 중 / 개원 예정 | 「개원 예정 시기」는 문의내용에 쓰도록 placeholder로 안내 |
| 5 | 문의 내용 | 여러 줄 텍스트 | 필수 | 현재 상황과 궁금한 점을 적어 주세요. 개원 예정이면 예정 시기도 함께. | 높이 4~5줄 |
| 6 | 개인정보 수집·이용 동의 | 동의 체크 | 필수 | 「개인정보 수집·이용에 동의합니다. [내용 보기]」 | **스크롤 박스 끄기**, 처리방침은 별도 페이지 링크로 |

**뺀 항목**: E-mail (전화로 연락하므로 불필요. 메일 회신이 꼭 필요하면 선택 항목으로 맨 뒤에), 전화번호 분리 입력.

## 2. 위젯 설정

- 버튼 문구: 「문의 보내기」 (Submit 금지)
- 전송 완료 메시지: 「문의가 접수되었습니다. 영업일 기준 1일 내에 032-710-2258 번호로 연락드립니다.」
- 알림: 관리자 이메일 알림 켜기 + 가능하면 문자/알림톡 알림까지 (아임웹 폼 알림 설정)
- 스팸 방지: 자동 입력 방지(캡차)는 끄고, 대신 「동의 체크 필수」와 짧은 전송 간격 제한 사용. 캡차는 모바일 이탈이 큽니다
- 폼 제목: 위젯 자체 제목은 끄고, 코드 위젯의 「상담 문의」 제목을 사용

## 3. 폼 주변 배치 (CONTACT 섹션)

아임웹 2단 컬럼: 좌 `06-contact/01-page-hero.html`(연락처 · 진행 3단계) / 우 폼 위젯.
지도는 좌측 OFFICE 줄의 「네이버 지도에서 보기」 링크로 대체. 큰 지도 임베드는 로딩만 무겁고 전환에 도움이 안 됩니다.

## 4. 개인정보 처리방침 페이지

아임웹에 `/privacy` 페이지를 하나 만들고 현재 스크롤 박스 안의 전문을 옮깁니다. 폼 동의 문구의 [내용 보기]와 푸터 「개인정보처리방침」이 이 페이지로 연결됩니다.

## 5. 적용 후 확인

- [ ] 모바일에서 항목 라벨 → 입력 → 다음 항목이 한 손으로 이어지는지
- [ ] 전화번호 칸을 누르면 숫자 키패드가 뜨는지
- [ ] 전송 후 완료 메시지와 관리자 알림이 실제로 오는지 (테스트 1회)
- [ ] 필수 미입력 시 에러 문구가 한글인지
