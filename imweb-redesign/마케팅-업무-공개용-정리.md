# 마케팅팀 업무 → 홈페이지 공개용 정리

작성: 2026-11-11 · 근거: 마케팅팀 SOP 4종(블로그 기획운영 · 월간 성과 분석 · 월간 보고서 · AI 자동화) + 주간 업무보고 1년치 + 인수인계 시트
목적: 내부 문서에서 **"이렇게 일해요"(과정)** 와 **"이런 걸 해드려요"(서비스)** 만 뽑아 홈페이지 마케팅 페이지에 쓸 문장으로 바꾼다.

---

## 1. 한 줄 요약 (마케팅을 모르는 분을 위해)

마케팅팀이 하는 일은 결국 **세 가지 반복**입니다.

1. **매달 초**: 병원에서 받은 전월 신환 데이터와 네이버 수치를 보고 "왜 늘었나/줄었나"를 분석해 **보고서**로 보냅니다.
2. **매달 말**: 그 분석을 바탕으로 **다음 달에 어떤 키워드로 어떤 글을 쓸지 계획표**를 짜고, 팀장이 검토합니다.
3. **매주·매일**: 글을 발행하고, 검색 순위를 확인하고, 리뷰에 답하고, 광고를 조정합니다.

홈페이지에는 이 **리듬**과 **검수 기준**, 그리고 **해주는 일의 목록**만 보여주면 됩니다. 병원 이름, 수치, 도구, 사람 이름, 내부 결재 구조는 빼면 됩니다.

## 2. 공개 기준

| 공개해도 되는 것 (홈페이지용) | 공개하면 안 되는 것 (내부용) |
|---|---|
| 한 달 업무 사이클 (초·중·말·매주) | 병원명과 모든 수치 (유입, 예약, 조회수, 광고비) |
| 키워드를 4종류로 나눠 기획한다는 방식 | 담당자 실명, 담당 병원 배정 |
| 콘텐츠 검수 5가지 기준 | 사용 도구명 (Make, Notion, ChatGPT, 블랙키위 등) |
| 보고서에 무엇이 들어가는지 | AI 자동화로 원고를 생성한다는 사실 (§5 결정 필요) |
| 담당자 + 서브담당자 + 팀장 3중 체계 (공백 없음) | 기안·검토·전결 같은 결재 구조 |
| 문제 생겼을 때 대응 원칙 (즉시 보류·수정·재검토) | 외주 인원 사용 |
| 서비스 항목 목록 | 초진접수증을 받는다는 표현 (개인정보 연상). "병원의 신환 데이터"로 순화 |
| 의료법 56조 기준으로 거른다는 사실 | 카페 댓글 작업, 리뷰 "작업" 같은 바이럴 세부 (「카페 제휴·이벤트」「리뷰 관리」로만) |
| | 인수인계 메모의 병원별 요청사항 전부 |

## 3. "이렇게 일해요" — 홈페이지용 문장

### 3-1. 한 달의 일 (진행 과정 섹션에 넣을 4단계 재구성)

| 시기 | 제목 | 문장 |
|---|---|---|
| 매달 초 | 데이터를 먼저 봅니다 | 전월 신환이 어느 지역에서 왔는지, 블로그·플레이스·광고 수치가 어떻게 움직였는지 채널별로 나눠 봅니다. 한 채널만 보고 판단하지 않습니다. |
| 매달 초 | 보고서를 보냅니다 | 메인 키워드의 PC·모바일 노출 순위 캡처, 광고 요약, 그리고 "왜 그랬는지"와 "다음 달엔 무엇을 바꿀지"를 담은 핵심 코멘트 2~3개. 원장님이 요약만 봐도 이해되는 구조로 씁니다. |
| 매달 말 | 다음 달 계획을 짭니다 | 키워드를 네 종류(지역+진료과 메인 / 인근 생활권 서브 / 계절·이슈 트렌드 / 병원 소식 브랜드)로 나눠 발행 계획표를 만들고, 담당자가 1차, 팀장이 2차로 검토합니다. |
| 매주 월요일 | 순위를 점검합니다 | 그 주에 발행한 키워드의 검색 노출 순위를 확인하고, 목표보다 낮은 키워드는 추가 콘텐츠로 보강합니다. |

### 3-2. 매일 하는 일 (한 줄 나열용)
리뷰 확인과 답글 · 플레이스 순위 확인 · 광고 잔액과 노출 확인 · 발행 전 검수

### 3-3. 발행 전 검수 5가지 (의료광고 심의 섹션 옆에)
1. 의료법 제56조 — 시술 효과 단정, 타 병원 비교 표현 없는지
2. 병원의 톤앤매너와 맞는지
3. 의학 용어와 오탈자
4. 이미지 저작권
5. 연락처·진료시간 같은 사실관계

문장: "글 하나가 나가기 전에 다섯 가지를 봅니다. 하나라도 걸리면 발행을 멈추고 고친 뒤 다시 검토합니다."

### 3-4. 담당자 체계 (마케팅 비서 섹션 보강)
- "병원마다 담당자와 서브담당자가 있고, 팀장이 전체를 봅니다. 담당자가 자리를 비워도 업무는 멈추지 않습니다."
- "문의는 담당자가 바로 받습니다." (팜플렛의 「10분 내 응답률 95%」는 최신 수치 확인 후 사용)

### 3-5. 문제가 생기면
- 순위가 떨어지면: 원인을 알고리즘 변동·경쟁 심화·콘텐츠 품질로 나눠 보고, 통제 가능한 것부터 손봅니다.
- 신환이 줄면: 온라인에서 고칠 수 있는 부분과 병원 쪽 요인을 구분해 말씀드립니다. 숫자만 보고하지 않습니다.
- 비수기에는 전월이 아니라 전년 같은 달과 비교합니다.

## 4. "이런 걸 해드려요" — 서비스 목록

주간 업무보고 1년치에서 실제로 반복된 일을 빈도순으로 묶었습니다. 홈페이지에는 **굵은 7개**를 카드로, 나머지는 태그로 쓰면 됩니다.

| 분류 | 서비스 | 실제로 하는 일 (내부 참고) | 공개 표현 |
|---|---|---|---|
| **네이버 플레이스** | 플레이스 관리 | 순위 확인, 대표·서브 이미지 교체, 예약·스마트콜 설정, 플레이스 광고 운영, 유입 채널 분석 | 지역+진료과 검색에서 먼저 보이도록 플레이스를 관리하고 광고를 운영합니다 |
| **블로그** | 공식 블로그 기획·발행 | 월 계약 건수 발행, 4종 키워드 기획, 검수, 발행, 순위 보강 | 매달 키워드 계획을 세우고 검수를 거쳐 발행합니다 |
| **키워드** | 키워드 전략 | 메인·서브·트렌드·브랜드 4종, 신환 유입 지역 기반 | 환자가 실제로 오는 동선을 기준으로 키워드를 고릅니다 |
| **검색광고** | 네이버 광고 운영 | 파워링크·플레이스 광고, 입찰가·키워드 조정, 예산 관리 | 필요한 시점에만 집행하고 전환 기준으로 예산을 조정합니다 |
| **리뷰** | 리뷰 관리 | 리뷰 확인·답글, 리뷰 이벤트 | 리뷰에 답하고, 실제 후기가 쌓이도록 이벤트를 설계합니다 |
| **SNS** | 카드뉴스·인스타그램 | 카드뉴스 제작, 인스타 운영, 메타 광고 분석 | 병원 톤에 맞춘 카드뉴스와 인스타그램 운영 |
| **보고** | 월간 성과 보고서 | 노출 순위 캡처, 광고 요약, 코멘트, 다음 달 방향 | 숫자마다 이유와 다음 달 계획이 붙은 보고서 |
| 홍보 | 언론 보도 | 뉴스 기사 원고·송출 | 원장님 전문성을 보여주는 기사 |
| 홍보 | 카카오톡 채널 | 채널 운영, 메시지 | 환자와 소통하는 카카오 채널 |
| 홍보 | 지역 커뮤니티 | 맘카페 제휴·이벤트, 당근 광고 | 맘카페 제휴와 지역 앱 광고 |
| 홍보 | 이벤트 기획 | 개원·시즌 이벤트, 포스터 연계 | 개원·시즌 이벤트 기획 |
| 운영 | 의료광고 심의 대응 | 심의 신청, 조건부 승인 수정 | 심의가 필요한 소재는 신청부터 수정까지 대신 합니다 |
| 운영 | 홈페이지 팝업·공지 | 팝업·공지 업데이트, 소식 반영 | 홈페이지가 멈춰 보이지 않게 소식을 올립니다 |
| 운영 | 지도 등록 | 네이버·카카오·구글 지도 | 3사 지도 등록 |
| 운영 | 개원 세팅 | 플레이스·블로그·광고 계정 개설 | 개원 전 온라인 채널 일괄 세팅 |

**뺀 것**: 카페 댓글 작업(표현 자체를 쓰지 않음), 접수증 수령·폐기, 비즈머니 잔액 관리(광고 운영에 포함), 영상·촬영(미디어 제외 원칙), AI 바이브코딩·AI 챌린지(내부 역량 개발).

## 5. 결정이 필요한 것

1. **AI 자동화 공개 여부.** SOP상 블로그 원고·이미지 초안은 자동화로 만들고 담당자가 검수합니다. 홈페이지에 "AI로 원고를 만든다"고 쓰면 원장님 입장에서는 "그럼 내 글은 기계가 쓰나"로 읽힐 수 있고, 애플 톤·AI 느낌 배제 방향과도 어긋납니다. **권장: 공개하지 않고 "담당자가 기획하고 다섯 가지 기준으로 검수합니다"까지만.** 굳이 쓴다면 "제작 도구는 자동화하고, 기획과 검수는 사람이 합니다" 한 줄.
2. **「10분 내 응답률 95%」** 팜플렛 수치의 최신 근거.
3. **맘카페** 표현. 「제휴·이벤트」까지만 쓸지, 아예 뺄지.
4. 월 발행 건수 같은 **계약 조건**은 홈페이지에 쓰지 않고 상담에서 안내 (권장).

## 6. 디자인 페이지 보강 (요청 반영)

디자인 페이지의 인쇄물 범위를 엑스배너 하나가 아니라 **원내 인쇄물 전체**로 넓힙니다. 인수인계 시트에도 봉투·포스터 제작 문의가 실제로 들어옵니다.

- 섹션 제목: 병원 안에서 환자가 손에 쥐는 것까지 만듭니다.
- 항목 (팜플렛 p.44~47 실물 이미지 그대로): **엑스배너 · 접수증 · 명함 · 포스터 · 전단지 · 안내문(수술 후 주의사항, 퇴원 안내) · 봉투 · 리뷰 이벤트 포스터 · 홈페이지 팝업 배너**
- 한 줄: 간판 업체, 인쇄소, 홈페이지 업체를 따로 찾지 않아도 됩니다. 한 톤으로 한 번에.
- 메인 페이지 「하는 일 두 가지」 디자인 카드의 태그도 같은 목록으로 교체.
