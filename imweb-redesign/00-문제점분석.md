## 3. 리디자인 방향 요약

- **톤**: 자사 포트폴리오 페이지(`/`)와 같은 라이트·미니멀. 검정 잉크 + 넓은 여백 + 브랜드 블루는 포인트로만.
- **구조**: 홈 9개 섹션(히어로 → 지표 → 서비스 → 차별점 → 사례 → 로고 월 → 과정 → 인사이트 → CTA), 서브 4~5개 섹션.
- **문장**: 기존 사이트의 좋은 문장을 살려 제목으로 승격. 치료 효과·비교 표현은 쓰지 않음(의료광고법).
- **전환**: 모든 페이지 하단에 동일한 CTA(30분 진단 미팅) + 전화 + 카톡.
